# BNDS Host Competition Timer · 主持人大赛计时

云服务器上运行的比赛计时工具。所有访问者看到**完全同一个**倒计时；只有带 `/set` 的入口能改动它。

## 一、访问地址

| 用途 | 地址 | 说明 |
|---|---|---|
| **大屏显示（只读）** | http://119.3.170.71/ | 投影 / 主持人屏 / 观众手机都用这个 |
| **竖条屏（256×736）** | http://119.3.170.71/v （= `/portrait`） | 时间竖排显示，适配窄长竖条屏 |
| **控制台（可设定）** | http://119.3.170.71/set | 只有这个页面能控制计时 |
| 备用端口（若现场网络屏蔽 80） | http://119.3.170.71:8080/ 与 `/set` | 内容完全一致，同一份状态 |

推荐用法：投影机开 `http://119.3.170.71/` 按 `F` 全屏；操控电脑开 `/set`。

## 二、现场怎么用

**控制台（`/set`）**

- 档位：`30s` / `90s` / `150s` 一键切换（点击后回到该档位的满值并暂停，等你按开始）
- 自定义：填「分 / 秒」后点「应用」或回车，范围 1 秒 – 99 分 59 秒
- `开始 / 暂停 / 继续`：同一个大按钮随状态变化
- `重置`：回到设定档位的满值并暂停（换人重来时用）
- `重新开始`：归零并立即开跑
- 微调：`−1分 −10秒 +10秒 +1分`，跑动中也能加时，无需重置
- 快捷键：`空格` 开始/暂停 · `R` 重置 · `Shift+R` 重新开始

**大屏（`/`）**

- 只显示剩余时间，别的什么都不显示；数字按 16:9 铺满（约 84% 屏宽）
- **倒数 10 秒起数字变红并闪动**（1 秒一个明暗周期）；到 00:00 闪得更强，同时整屏底色微微泛红（无提示音）
- 阈值以屏幕上的数字为准：显示 `00:10` 的那一刻开始闪红，`00:11` 还不闪
- `F` 键全屏；支持 Wake Lock 的设备上会自动阻止息屏
- 页面上没有任何按钮，也没有控制接口 → 观众端只能看

**侧屏（竖条屏，`/v`）**

- 侧屏 LED 接在 **16:9 输出（1600×900 / 1920×1080 均可）的左上角**，占 **256×736 个物理像素**。
  所以这个页面本身就是一张 16:9 画布，**所有画面只在左上角 256×736 的区域里渲染**，
  区域外不显示在 LED 上（画布其余部分用了接近屏幕底的浅灰填充，配接有几像素偏差也不突兀）。
- 区域尺寸按 `物理像素 ÷ devicePixelRatio` 换算，落在 LED 上的物理像素数永远不变：
  - 系统缩放 100%（dpr=1）→ 区域 = 256×736 CSS px（1600×900 与 1920×1080 输出都一样）
  - 系统缩放 150% / 200%（dpr=1.5 / 2）→ 自动换算为 171×491 / 128×368 CSS px
- 临时接别的尺寸或要现场对准时，可用 `?w=256&h=736` 覆盖区域尺寸、`?debug=1` 画出该区域红框
- **时间竖着排**，每一位数字各占一行（如 `0` `2` `:` `3` `0` 自上而下），
  冒号与数字行等高，两个点都完整显示
- 值与主大屏完全同源，倒计时会同样变红闪动、归零整屏泛红
- 顶部是标识（居中）。**标识也按高度比例（8.5cqh）定尺寸**，与时钟同处一套 cqh 预算，
  所以任何屏幕尺寸下位置与比例都一致；走时态与休息态下 logo 位置完全相同
- 冒号行与数字行等高（1em），两个点都完整可见
- 用 `cqh` 容器单位按高度精确分配空间；不支持容器查询的老浏览器会自动退回 `vh` 计算，仍能完整显示
- 页面同样是只读的，没有任何控制入口

**休息模式（在 `/set` 里开关）**

- 打开后**所有大屏（主大屏 + 竖条屏）不再显示剩余时间**，改显示「**2026主持人大赛**」
  - 主大屏（16:9）：整串排成一行显示
  - 竖条屏：整串**竖着写**（自上而下，9 个字），且**所有字等大**；
    每个字一行、行高精确 1em，总高 = 9.3em ≈ 81% 可用高度（每字约 62px），
    全部用 `cqh` 预算 —— 即使视口比 736 矮（浏览器工具栏占掉高度）也会等比缩小，
    不会顶到 logo、也不会把最后一个字切掉
- 打开休息时若计时正在走，会**先自动暂停**并把剩余时间冻住，避免倒计时在看不见的地方跑完
- 按「开始 / 继续 / 重新开始」会**自动退出休息** —— 要跑计时就必须让大屏显示计时，
  防止出现"以为在计时、其实大屏还挂着标题"的现场事故
- 休息状态会随服务端一起持久化：服务器重启后仍然是休息状态

## 三、标识（Logo）

- 位置：大屏页左上角、控制台顶栏左侧。透明底，不遮挡计时数字。
- 尺寸：大屏 `clamp(112px, 11vw, 252px)` 宽（16:9 下约 211px 宽、占屏宽约 11%）；控制台固定高 34px。
- 资源：`public/logo.webp`（50 KB，所有现代浏览器优先使用）+ `public/logo.png`（252 KB，老浏览器兜底），
  两张都已按 alpha 精确裁掉四周留白、并清零透明区 RGB（避免黑边、利于压缩）。
  源文件保留为 `logo源文件-透明版.png`（1280×630，你提供的那张）。
- 想改大小：调 `public/style.css` 里 `.corner-logo { width: … }`（大屏）或 `.brand-logo img { height: … }`（控制台）。
- 想彻底去掉：删掉 `public/index.html` 里的 `<picture class="corner-logo">…</picture>` 那段即可。

## 四、精度与同步

- 服务端是唯一真值源，只保存「设定时长 + 是否运行 + 截止时刻」，不逐秒广播；
  各端拿到截止时刻后**本地按毫秒插值**，所以画面平滑、不跳秒，推送短暂中断也照常准确走时。
- 下载页面时会做一次往返校时，**设备本身时钟不准也会显示正确数值**。
- 实测：2 秒样本误差 0、15 秒累计漂移 0 ms（以服务器时钟为基准）；
  服务器 chrony 与 NTP 偏差 9 µs。
- 传输用 SSE（`EventSource`），浏览器自带断线自动重连；连不上时自动降级为每秒轮询。
  断线时大屏左下角出现一个小提示，恢复后自动消失并对齐。

## 五、运维命令（在服务器上执行）

```bash
systemctl status bnds-timer      # 状态
systemctl restart bnds-timer     # 重启
journalctl -u bnds-timer -f      # 实时日志
journalctl -u bnds-timer --since "-1h"   # 最近一小时日志
```

- 服务已 `enable`：**服务器重启/断电恢复后自动拉起**（已实测）。
- 进程以非 root 用户 `bnds` 运行，仅被授予监听 80 端口的能力；
  文件系统只读（`ProtectSystem=strict`），唯一可写目录 `/var/lib/bnds-timer`
  （里面只存一个 `state.json`，用于崩溃/重启后恢复档位与进度）。
- `systemd-analyze security bnds-timer` 评分 3.9 / OK。

## 七、应急预案

| 情况 | 处理 |
|---|---|
| 服务器重启 / 断电 | 无需操作，约 1 分钟自动恢复；恢复后是**暂停态**，档位与进度保留，按「继续」即可 |
| 进程崩溃 | systemd 1.5 秒内自动拉起（已实测 `kill -9`），进度按最后记录值恢复为暂停态 |
| 现场网络抖动 | 大屏数字继续准确走（本地插值）；网络恢复后多端自动对齐 |
| 80 端口被现场网络屏蔽 | 改用 `http://119.3.170.71:8080/` |
| 主持人临时加时 | 控制台点 `+10秒 / +1分`，跑动中即可生效 |
| 中场休息 | 控制台点「开启休息 · 大屏显示标题」，所有大屏显示赛事标题；休息结束按「开始」或「结束休息」 |
| 竖条屏没有画面 | 用 `http://119.3.170.71/v`；若现场网络屏蔽 80，换 `:8080/v` |
| 误按「重置」 | 按「继续」前先重设档位；若已跑动，可用微调补回时间 |

## 八、安全说明（重要）

按需求，**`/set` 不需要口令**：任何知道该地址的人都能控制计时。
如需锁上，在 `/etc/systemd/system/bnds-timer.service` 里加一行
`Environment=CONTROL_KEY=你的口令`，`systemctl daemon-reload && systemctl restart bnds-timer`
后，只有 `http://119.3.170.71/set?k=你的口令` 才能控制（服务端强制校验，返回 403）。
当前为 HTTP（无 HTTPS）；若之后绑定域名，可用 certbot 一键签发证书。
